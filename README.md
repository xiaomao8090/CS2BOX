# CS2 盒子

一个给 CS2 玩家用的本地小工具。平时要开控制台、翻配置文件、到处查的东西，凑到一个界面里。

Windows 10 / 11，自带运行时，不用装 .NET。界面是 Win11 那种风格，跟随系统深浅色。

## 能干什么

- **账号切换**：不退 Steam 就能换号（前提是那个号登录时勾过"记住密码"）
- **启动项**：勾常用参数，也能直接写进 Steam 的启动选项
- **准星**：调参数、实时预览，能和分享码（`CSGO-xxxxx-…`）互相转
- **视频设置**：改分辨率、宽高比、刷新率、画质
- **按键绑定**：一套常用模板，填好键一键写进 autoexec.cfg
- **职业选手**：收了些选手的准星和灵敏度，按你自己的 DPI 换算完能直接套
- **配置文件**：备份、还原，换号时自动备一次
- **服务器延迟**：测到各个节点的 ping，国内的显示中文名
- **录像**：管本机的 demo，能放、能删、能清旧的
- **创意工坊**：管已经下好的地图
- **国服认证**：蒸汽平台实名的表单辅助填写

## 怎么用

解压出来，双击 `CS2Box.exe`。第一次打开会先弹一份免责声明，看完勾同意才能进。

`Data` 文件夹得跟 `exe` 放一块，里面是自带的职业选手数据，删了那个功能就空了。

除了服务器延迟和国服认证，别的都不用联网。

## 自己编译

```
git clone https://github.com/xiaomao8090/CS2BOX.git
cd CS2BOX
dotnet build -c Release
```

要装 .NET 8 SDK。

## 关于数据

不上传任何东西到我的服务器——我压根没服务器。账号信息读的是你本机 Steam 自己的文件，设置都存在 `%AppData%\CS2Box` 里，删了那个文件夹就等于重置。国服认证填的姓名、身份证、手机号、验证码只在内存里过一遍，关了就没了，不写日志也不上传。
