CS2 盒子  CS2Box
作者 xiaomao
版本 0 1 0
开源免费

这是什么
一个给 CS2 玩家用的小工具
把平时要开控制台 翻配置文件 到处查的东西
集中到一个界面里

功能
账号切换 不用退出 Steam 就能换号
启动项 勾选常用参数 也能直接写进 Steam
准星 调参数 实时预览 支持和分享码互转
视频设置 改分辨率和宽高比
按键绑定 一套模板改完一键应用
职业选手 看选手的准星和设置 能直接套用
配置文件 备份和还原 换号自动备份
服务器延迟 测到各个节点的延迟
录像 管理本机 demo
创意工坊 管理已下载的地图
国服认证 蒸汽平台实名认证的表单辅助填写

运行要求
Windows 10 或 Windows 11 六十四位
不需要安装 NET 运行时
不需要联网 除延迟测试和国服认证

怎么用
把整个文件夹解压出来
双击 CS2Box exe
第一次打开会先弹一份免责声明
读完勾选同意才能继续
Data 文件夹必须和 exe 放在一起
里面是本机自带的职业选手数据
删了这个功能就空了
